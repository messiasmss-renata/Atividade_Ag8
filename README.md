# 👩🏻‍💻👥❤️ Lista De amigos ❤️👥👩🏻‍💻

Projeto desenvolvido na disciplina de Programação Web, com a criação de um sistema de cadastro de amigos utilizando PHP, MySQL e MySQLi. A atividade aborda conceitos de login e senha, sessões, controle de acesso, operações CRUD (cadastrar, listar, atualizar e excluir), conexão com banco de dados e uso de arquivos reutilizáveis com include e require_once.
